# MatchFlow Frontend

React-клиент для Django REST API проекта MatchFlow.

## Запуск

```bash
cd frontend
npm install
npm start
```

По умолчанию API вызывается через `/api`, а `package.json` содержит proxy на `http://localhost:8000`. Поэтому в режиме разработки достаточно запустить Django backend на 8000 порту.

Для отдельного домена backend создайте `.env`:

```env
REACT_APP_API_URL=http://localhost:8000/api
```

## Что реализовано

- регистрация и вход по email/password;
- хранение DRF Token в `localStorage`;
- cookie-переключатель светлой/тёмной темы;
- публичные страницы команд, турниров и матчей;
- поиск, фильтры и пагинация через query-параметры backend;
- личный кабинет и редактирование профиля;
- создание команды капитаном;
- заявка игрока на вступление в команду;
- рассмотрение заявок игроков капитаном;
- подтверждение организатора с загрузкой документа;
- создание турнира с загрузкой подтверждающего документа;
- подача команды на турнир;
- рассмотрение заявок команд организатором;
- подписка/отписка от турниров и страница «Мои турниры»;
- список матчей, карточка матча, создание матча, отмена и внесение результата.

## Важные замечания по backend API

В текущем backend нет отдельных endpoints для списка стадионов и подробной карточки команды. Поэтому frontend:

- для `Stadium` использует ручной ввод ID площадки;
- для карточки команды сначала пробует `/api/teams/<id>/`, а если endpoint отсутствует, ищет команду в `/api/teams/?page_size=50`.

Когда backend добавит `/api/stadiums/` и `/api/teams/<id>/`, frontend можно будет легко расширить в `src/api/client.js`.
